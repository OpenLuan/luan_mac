# LuanMac

macOS host for [Luan](https://github.com/OpenLuan) — embeds Lua 5.3.3, [luafan](https://github.com/luafan/luafan), and the Luan runtime.

**License:** MIT (see [LICENSE](LICENSE)). Third-party: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), [lua-apple/THIRD_PARTY.md](lua-apple/THIRD_PARTY.md).

## Layout

| Path | Role |
|------|------|
| `LuanMac/` | SwiftUI app + ObjC Lua bridge |
| `LuanCLI/` | `luan` CLI tool |
| `luan/` | **git submodule** → LUAN source and shared runtime logic |
| `webase/` | **git submodule** → webase base runtime layer |
| `lua-apple/` | Native stack (Lua, libevent, utlua, PAL, …) |
| `lua-apple/luafan/` | **git submodule** → luafan |
| `lua-apple/libevent/` | **git submodule** → libevent (`release-2.1.12-stable`) |
| `lua-apple/lua53/` | **git submodule** → Lua (`v5.3.3`) |
| `lua-apple/third_party/brotli/` | **git submodule** → Brotli; compiled from its `c/` subtree |
| `lua-apple/third_party/lua-openssl/` | **git submodule** → lua-openssl fork (`OpenLuan/lua-openssl`, branch `luan-eaa7923`); compiled directly from `src/` + `deps/auxiliar` |
| `lua-apple/third_party/openssl/` | **git submodule** → OpenSSL (`openssl-3.0.18`); built to `Frameworks/` via `scripts/build_xcframeworks.sh` |
| `lua-apple/luauser.c` | First-party `LUA_USER_H` lock hooks (not upstream Lua) |
| `lua-apple/platform/libevent-config/macos/` | Generated libevent headers (not upstream) |
| `runtime/` | Generated runtime from `scripts/build_runtime.sh` (`runtime/cacert.pem` is tracked) |
| `Frameworks/` | Build outputs: OpenSSL / curl-impersonate xcframeworks (gitignored; generated by `scripts/build_xcframeworks.sh`) |
| `project.yml` | XcodeGen project definition |

## Build

```bash
git submodule update --init --recursive
./scripts/build_runtime.sh  # also validates all published web/*.js syntax
brew install xcodegen
xcodegen generate
./scripts/build_xcframeworks.sh macos
xcodebuild -project LuanMac.xcodeproj \\
  -scheme LuanMac \\
  -configuration Release \\
  -derivedDataPath build \\
  CODE_SIGN_IDENTITY="-" \\
  CODE_SIGNING_REQUIRED=NO \\
  CODE_SIGNING_ALLOWED=NO \\
  ONLY_ACTIVE_ARCH=NO
```

The `runtime/` directory is generated by `scripts/build_runtime.sh`.

To publish a macOS DMG, push a semantic version tag such as `v0.1.0`. The
GitHub Actions build will create a GitHub Release and attach `LuanMac.dmg`.

Local CLI smoke test: `scripts/run_cli_temp.sh` (test-only JWT/activation defaults).

## Submodules

See `.gitmodules`:

- `luan` → `https://github.com/OpenLuan/luan.git` (pinned by the parent repository; source of the shared LUAN runtime)
- `webase` → `https://github.com/luafan/webase.git` (pinned by the parent repository; base runtime layer)
- `lua-apple/luafan` → `https://github.com/luafan/luafan.git`
- `lua-apple/libevent` → `https://github.com/libevent/libevent.git` (pinned to `release-2.1.12-stable`; generated headers stay in `lua-apple/platform/libevent-config/macos/`)
- `lua-apple/lua53` → `https://github.com/lua/lua.git` (pinned to `v5.3.3`; Lua locking is provided by `luauser` / `LUA_USER_H`, see `patches/lua-5.3.3/README.md`)
- `lua-apple/third_party/brotli` → `https://github.com/google/brotli.git` (compiled from its `c/` subtree; Lua binding remains first-party)
- `lua-apple/third_party/lua-openssl` → `https://github.com/OpenLuan/lua-openssl.git` (fork pinned to branch `luan-eaa7923`, compiled from `src/` and `deps/auxiliar`; `git submodule update --init --recursive` fetches its nested dependencies)
- `lua-apple/third_party/openssl` → `https://github.com/openssl/openssl.git` (pinned to `openssl-3.0.18`; built with `scripts/build_xcframeworks.sh`)

Other deps are vendored with upstream LICENSE files and pin notes in `lua-apple/THIRD_PARTY.md`.

To bump LUAN or webase, update the checkout under `luan/` or `webase/`, verify the generated runtime, then commit only the relevant submodule pointer in this repository. Pushes are intentionally separate from this build integration.

## Notes

- Apple builds use `-DLUA_USER_H="<luauser.h>"` with `lua-apple/luauser.c`; Linux Docker uses luafan `fan_lua_lock`.
- `runtime/sites/` is local data and is gitignored.
